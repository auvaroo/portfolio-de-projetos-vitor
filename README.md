# 💵🔥 Portfólio Pessoal

Este é o meu portfólio online, desenvolvido para apresentar minhas habilidades, projetos e formas de contato.  
O design combina uma **paleta em preto e verde escuro**, com recursos de **acessibilidade** e animações suaves.

## ✨ Funcionalidades

- ⚙️ **Menu de acessibilidade** com:
  - Ativar/desativar **alto contraste**
  - **Aumentar** e **diminuir fonte**
- 💻 **Seções principais**:
  - Início
  - Sobre mim
  - Projetos
  - Contato
- 🎬 **Animações de entrada** usando [ScrollReveal](https://scrollrevealjs.org/).
- 📱 **Layout responsivo**, adaptado para celular e desktop.

## 🛠️ Tecnologias utilizadas

- **HTML5** para estrutura
- **CSS3** (customizado) para estilos
- **JavaScript** para interatividade
- **ScrollReveal** para animações
- **Google Fonts – Chakra Petch** para tipografia
